# Dead Pixel — Profile Site

## Folder structure

```
website/
├── index.html        Main page (do not put JS/CSS logic directly in here)
├── styles/            All CSS lives here
│   └── style.css
├── src/                All TypeScript source lives here
│   └── main.ts
├── assets/             Images/icons go here (empty for now)
├── dist/                Compiled JS output — generated by the build, not committed
├── tsconfig.json
├── package.json
└── .gitignore
```

Future JS, CSS, or other code should go in its own folder the same way
(`styles/`, `src/`, `assets/`) rather than mixed into `index.html`.

## How the TypeScript build works

`src/main.ts` is written in TypeScript. It's compiled to plain JavaScript
in `dist/main.js`, which `index.html` loads. You never edit `dist/` by
hand — it's regenerated every build.

## Deploying with Cloudflare Pages

When you connect this GitHub repo to Cloudflare Pages, use these build
settings:

- **Build command:** `npm install && npm run build`
- **Build output directory:** `/` (the project root)

Cloudflare will install TypeScript, run `tsc` to generate `dist/main.js`,
then serve the whole project. No manual build step needed on your end —
every push to the repo triggers a new deploy automatically.
