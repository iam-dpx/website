Customize me, no code required

A Discord bot controlled entirely by slash commands — change its nickname per server, or its name/avatar everywhere, without ever touching the bot's code.

What it does

Most bots ship with a fixed name and picture the server has no say over. This one hands that control to whoever's running the server, through three commands.

Commands

/setnickname <name>

Changes the bot's nickname in that server only. Anyone with "Manage Nicknames" can run it. No rate limit worth mentioning.

/setname <name>

Changes the bot's actual username — but Discord makes this change everywhere the bot is added, not just in the server that ran the command. Admin-only by default. Discord allows roughly 2 of these per hour.

/setavatar <image url>

Changes the bot's profile picture — also global across every server, same as above. Admin-only by default. Discord allows roughly one change every 10 minutes.

How it's built

Runs on Cloudflare Workers, not a traditional always-on bot host. Discord sends each slash command as a plain HTTP request straight to the Worker instead of needing a persistent connection — so there's no server running 24/7, just a function that wakes up, responds, and goes back to sleep.

Trade-off: no live custom status message (like "Playing Minecraft") — that specifically requires the persistent connection this bot intentionally doesn't use.
